# SAGEBench data

Two layouts:

```
data/
├── refs/         symlinks into existing simulated datasets on this host
└── ci-smoke/     newly-generated tiny .d files (gitignored)
```

## `data/refs/`

| Symlink            | Target                                                                                  |
|--------------------|-----------------------------------------------------------------------------------------|
| `hela-150k-g30m`   | `SUBMISSION/MBR/data/150K_G30M/TIMSIM-DDA-HELA-150K-G30M-001`                          |
| `hla-10k`          | `SUBMISSION/zenodo/hla/hla/timsim-hla-thunder-topN/thunder-10K`                        |
| `hla-100k`         | `SUBMISSION/zenodo/hla/hla/timsim-hla-thunder-topN/thunder-100K`                       |

The symlinks are local-only — they only resolve on this build host.
For external use the matching Zenodo deposits (built via
`scripts/prepare_zenodo_bundle.sh`) are the canonical distribution.

## `data/ci-smoke/`

Generated by `scripts/generate_hela_ci_smoke.sh`. Two run directories,
each containing a `.d` directory plus the per-run ground-truth DB.
Gitignored.

```
data/ci-smoke/
├── _rendered_configs/
│   ├── hela-ci-smoke-rep001.toml
│   └── hela-ci-smoke-rep002.toml
├── arguments-SAGEBENCH-CI-HELA-SMOKE-001.txt   ← provenance dump from timsim
├── arguments-SAGEBENCH-CI-HELA-SMOKE-002.txt
├── SAGEBENCH-CI-HELA-SMOKE-001/
│   ├── synthetic_data.db                       ← ground truth (1,236 pairs)
│   └── SAGEBENCH-CI-HELA-SMOKE-001.d/
│       ├── analysis.tdf
│       └── analysis.tdf_bin
└── SAGEBENCH-CI-HELA-SMOKE-002/
    ├── synthetic_data.db                       ← ground truth (1,256 pairs)
    └── SAGEBENCH-CI-HELA-SMOKE-002.d/
        ├── analysis.tdf
        └── analysis.tdf_bin
```

Sage takes the inner `.d` directories as positional inputs; the
`synthetic_data.db` next to each is what `python -m sagebench eval`
joins against. Together the two reps cover **1,448** distinct
(sequence, charge) precursors after `ground_truth.union()`.
