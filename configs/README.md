## Schema

All configs use the post-refactor TimSim TOML schema introduced on the
`feature/simulate-from-findings` branch (commit 03398133+):

```
[paths]        save_path, reference_path, fasta_path, findings_path, modifications, existing_path
[experiment]   acquisition_type, gradient_length, from_findings, from_existing, ...
[digestion]    cleave_at, missed_cleavages, min_len, max_len, ...    # FASTA-mode only
[models]       rt_model, ccs_model, intensity_model
[retention_time] [ion_mobility] [charge_states] [isotopic_pattern] [fragment_intensity]
[noise] [variation] [acquisition] [dda] [proteome_mix] [phosphorylation]
[performance] [logging] [video_settings]
```

For `from_findings = true` (the CI smoke), `[digestion]` is omitted —
TimSim reads peptides directly from the seed CSV instead of digesting
a FASTA. See `seeds/hela_ci_smoke.csv` for the exact peptide list.

## Running

```bash
# CI smoke (fresh):
timsim configs/hela-ci-smoke.toml

# Existing eval datasets — the configs are kept here for documentation;
# the .d already lives under data/refs/. To regenerate from scratch,
# point save_path at a clean dir and re-run timsim.
```
